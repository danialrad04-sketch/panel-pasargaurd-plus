# Defensive Review

Read the changed files and affected callers. Check ownership and role enforcement, server-side validation, least privilege, redaction, and dependency provenance. Use static review and local regression checks with synthetic fixtures. Review the existing API and frontend CodeQL workflows when evidence is available. Report findings with file and line, impact, and a concrete remediation. Keep credentials, production records, and receipt images out of review output.
