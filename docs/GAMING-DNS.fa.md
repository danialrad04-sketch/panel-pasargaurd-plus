# DNS گیمینگ (دورزدن تحریم)

از صفحهٔ «SmartDNS» → «ساخت پروفایل گیمینگ». پنل یک‌جا این‌ها را می‌سازد:

1. سیاست DNS برای سرویس‌های انتخابی (PlayStation، Xbox، Steam، …) که دامنه‌ها را به IP عمومی gateway هدایت می‌کند.
2. یک مسیر gateway (حالت sniff، TCP ۸۰ و ۴۴۳) برای هر دامنهٔ والد؛ زیردامنه‌ها زیر والدشان می‌روند.
3. شنوندهٔ DNS نود (پورت ۵۳) در صورت غیرفعال بودن.

## پیش‌نیازها
- متغیر `SMARTDNS_PANEL_URL` (آدرس HTTPS پنل) تنظیم شده باشد.
- نود متصل باشد و افزونهٔ SmartDNS (قرارداد ۱ با byte lease) روی آن نصب باشد (نصب خودکار نود).
- پورت‌های ۸۰/۴۴۳ و ۵۳ روی نود آزاد و در فایروال ارائه‌دهنده باز باشند.
- اگر نود gateway داخل ایران است، حتماً «تونل خروجی» انتخاب کنید؛ وگرنه سرویس‌ها IP ایران را می‌بینند و تحریم دور نمی‌خورد.

## روند
1. «بررسی پیش از اجرا» فقط‌خواندنی است و همهٔ مانع‌ها (blocker) و هشدارها را می‌گوید.
2. «ساخت و اعمال» همه‌چیز را در یک تراکنش ذخیره می‌کند (یا هیچ‌چیز) و سپس روی نود اعمال می‌کند. اگر نود تأیید نکند، تنظیمات بسته (fail-closed) می‌ماند و «تلاش دوباره» کافی است.
3. «اتصال کاربر»: کاربر، حداکثر ۳ IP عمومی و سقف حجم را بدهید. بدون این مرحله هیچ ترافیکی عبور نمی‌کند. روی دستگاه بازیکن DNS را روی IP نود بگذارید.

## محدودیت‌ها (صادقانه)
- فقط TCP از gateway عبور می‌کند؛ UDP بازی‌ها پوشش داده نمی‌شود.
- کارکرد هر بازی، تأخیر و پایداری روی شبکهٔ واقعی هنوز آزمون نشده است (`game_acceptance: untested`).
- لیست دامنه‌ها از کاتالوگ داخلی است؛ بازی با دامنهٔ خارج از کاتالوگ پوشش داده نمی‌شود.
